# 📈 Series_Temporais

Projeto de estudos e experimentos em **Séries Temporais** utilizando Python e Jupyter Notebook, com foco em análise exploratória, visualização de dados, decomposição temporal e correlação entre variáveis ambientais.

---

## 📌 Sobre o Projeto

Este repositório reúne notebooks desenvolvidos para praticar conceitos de séries temporais aplicados a bases reais de dados ambientais.

Os experimentos utilizam conjuntos de dados relacionados à:

- 🌫️ Qualidade do ar  
- 🌦️ Dados meteorológicos horários de Fortaleza  

O objetivo é compreender padrões ao longo do tempo, tendências, sazonalidade e relações entre variáveis.

---

## 🎯 Objetivo Acadêmico

Projeto desenvolvido com finalidade educacional para aprendizado de:

Ciência de Dados
Estatística aplicada
Modelagem temporal
Análise exploratória de dados
